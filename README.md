# CleanShelf

CleanShelf is a Batocera 43 refresh of **[Sheezie2Clean](https://github.com/Sheezie/Sheezie2Clean)
by Sheezie (newFUNKYmode)**. The layout, the five gamelist views, dark mode and all of the
hand-made system artwork are Sheezie's work. CleanShelf keeps them as they are and fills
the gaps that newer Batocera versions opened up.

If you like how it looks, the credit goes to Sheezie. See Sheezie2Clean's page for the
original screenshots.

Version 0.0.2. Tested on Batocera 43.1 (x86_64).

## What changed from Sheezie2Clean

* **A page for every system Batocera 43.1 lists.** 149 new system folders and the 4
  missing automatic collections (All Games, Wheel, Spinner, Trackball) get a name, maker,
  short description, a colour, and text wordmarks in Fira Sans. They are generated by
  `tools/gen-systems.py` from Batocera's `es_systems.cfg`, with wordmarks by `tools/mklogo.py`.
  Systems Sheezie drew keep Sheezie's artwork. A hand-made logo set can replace any generated one.
* **No blank white pages or white-on-white lists.** Any system that still has no folder
  gets a fallback in the root `theme.xml`: name and maker on the system page, a colour
  panel with random art from that system's games (or its wordmark), the coloured list
  panel in the basic, detailed and grid views, and a readable carousel and header label.
* **Mega CD** (Batocera 43's name for `segacd`) uses Sheezie's Sega CD artwork.
* **Splash:** the loading text is white, so it is visible on the black splash.
* **Menu switches:** Batocera 43 draws the theme's star switches as a squashed sliver, so
  CleanShelf leaves the switches to ES.
* **Grid view:** the game name is white on the coloured panel.
* Unused "- Copy" images removed.

## Install

1. Copy this folder to `/userdata/themes/CleanShelf` on your Batocera box (for example
   through the `share` network folder, `themes/CleanShelf`).
2. In Batocera: **Main menu > User interface settings > Theme set > CleanShelf**.
3. Optional: **Theme configuration > Dark mode**.

To regenerate system folders after a Batocera update (Python 3 with Pillow):

    python3 tools/gen-systems.py /usr/share/emulationstation/es_systems.cfg

Existing folders are left alone unless `--force` is given.

## Optional extras for RomM-o-Cera users

CleanShelf includes two additions for people who use RomM-o-Cera, a RomM client for
Batocera. Both are optional and change nothing for anyone else.

* **Pygame system page** (`pygame/`): artwork for the Pygame system, where RomM-o-Cera
  is listed. `tools/mkbg-pygame.py` draws the background.
* **"RomM Detailed" gamelist view**: the detailed view, using the title screen,
  fanart and series information that RomM-o-Cera saves for installed games. Choose it
  under **View options > Gamelist view style**. Games without that media look the same
  as in the normal detailed view.
